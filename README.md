# London Police Archive System

A retro-styled interactive detective game featuring:
- CRT monitor visual effects with scanlines and flicker
- Audio log playback system
- Clue collection mechanics
- Suspect accusation system

## Files
- `index.html` - Main game interface

## Setup
Open `index.html` in a web browser to play.

## Images Needed
The game references the following images (add your own):
- `default_scene.png` - Default scene image
- `detective.png` - Detective log scene
- `reporter.png` - Reporter record scene
- `witness.png` - Witness statement scene
